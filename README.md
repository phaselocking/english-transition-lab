# English Transition Lab

英语学习过渡实验室 · 交互式研究网页原型 0.1。

这是一份可以本地运行的研究体验原型。它通过模拟的全英文 seminar 情境，引导参与者探索学习经历，并让研究小组继续讨论问题和方法。它不是英语水平测试，也不是正式问卷或调查系统。

## GitHub 与在线发布

本项目是无构建步骤的静态网页，可以直接使用 GitHub Pages 发布。将仓库的 Pages 发布源设为 `main` 分支、`/(root)` 根目录即可；后续推送到 `main` 后，GitHub 会重新部署网页。

仓库公开的是原型源码和演示截图。网页仍只在浏览器内存中处理选择，不会因为上线而开始收集数据。

日常修改内容后，在项目目录运行：

```powershell
git add content.js README.md
git commit -m "Update research content"
git push
```

如果修改了其他文件，也需要将相应文件加入提交。

## 本地运行

**直接打开：** 双击项目中的 `index.html`，用电脑浏览器打开即可。无需安装依赖、联网或构建。

**可选本地预览：** 如果电脑已安装 Node.js，在项目文件夹中打开终端，运行：

```powershell
node server.mjs
```

然后打开终端显示的本地地址。按 `Ctrl+C` 停止服务器。服务器只用于提供本项目的静态文件。

## 当前可以做什么

- 从模拟 seminar 进入四条不同路径；入口选择会改变后续情境、追问、反馈和推荐探索主题。
- 在课堂指令、开口表达、课前准备、学术英语、支持资源五个主题之间自由切换。
- 在各个探索主题中尝试不同选择，查看对应反馈与简短内容。
- 返回上一步、重新开始，或换一条路径继续探索。
- 阅读三篇研究手记，了解研究动机、开放问题和后续计划。
- 在电脑和手机窄屏上浏览；使用键盘操作按钮和链接。

## 当前不能做什么

- 不收集、传输或保存真实个人信息；不提供真实问卷提交、访谈预约或经验投稿。
- 不保存选择或浏览进度；页面刷新或关闭后，本次体验的内存状态会清空。
- 不包含数据库、账号、登录、后台、统计分析或外部 API。
- 不生成英语能力评分、学习者分类或心理判断。
- 不展示虚构的调查结果、参与者原话或已经开展访谈的假象。
- 不提供网页内的内容编辑后台；研究手记通过修改内容文件更新。

页面内链接到的学习资源只是可选阅读；只有主动打开外部链接时才会离开本地网页。网页本身不加载远程字体、图片或分析脚本。

## 文件结构与维护

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构与静态展示内容 |
| `styles.css` | 颜色、版式、交互反馈和响应式样式 |
| `content.js` | 四条入口路径、五个探索主题、学习资源与研究手记 |
| `app.js` | 内存状态、内容切换、返回与重新开始逻辑 |
| `server.mjs` | 可选的本地静态文件预览服务器 |
| `README.md` | 运行方法、维护说明与原型边界 |
| `screenshots/` | 本次浏览器检查保存的桌面、手机截图，不参与网页运行 |

`content.js` 使用普通 JavaScript 对象 `window.LAB_CONTENT` 保存内容，不使用模块或网络请求，因此直接打开文件也能运行。

后续更新时，优先修改 `content.js`：

- `branches`：入口路径，每条包含独立追问、选项反馈和带走的问题。
- `topics`：探索情境、反馈、可尝试的做法、来源与待研究问题。
- `journals`：研究手记，可沿用现有字段增加新条目。

保留主题 `id` 的对应关系；如果新增主题或改变数据字段，应同时检查 `app.js` 的使用方式。文本以普通内容呈现，不应在内容字段中加入任意 HTML。

## 内容与研究边界

情境中的英文指令、对话和反馈均为原型编写的模拟示例，不能当作真实参与者材料。四条入口与五个主题是探索方向，不代表已经证实的困难分类。

有出处的学习概念与建议在页面中标注来源；资源链接及相关内容保存在 `content.js`。官方学习资源所建议的做法，也不等于已经验证适用于本项目所有参与者。个人经历、研究假设、模拟示例与未来真实研究发现应继续分别标注。

当前参考资料：

- [University of Kent · Learning from seminars](https://student.kent.ac.uk/studies/learning-from-seminars)：支持课前回看笔记、完成指定阅读、准备简短摘要和澄清问题。页面中的“一页纸”结构是原型练习，不是该指南验证过的教学方案。
- [University of Sussex · Presentations, seminars and group work](https://www.sussex.ac.uk/skills-hub/presentations-and-group-work)：支持把观点记成要点、倾听并回应、请求澄清。原型中的英文开头和三步练习为示例，不代表已经证明能降低焦虑。
- [British Council · English for Academic Purposes](https://www.teachingenglish.org.uk/professional-development/teachers/knowing-subject/teaching-english-academic-purposes-eap)：用于说明 EAP 的学习与研究语境，涉及 seminar、阅读与写作。它不是英语水平诊断，也不验证本项目提出的困难分类。

研究手记中的后续活动均为计划。若将来开展正式研究，需要另外设计参与方式、知情同意、退出机制、资料保护和研究方法；当前原型没有实现这些流程。

## 本次验证

通过 `node server.mjs` 实际启动网页，并在浏览器中检查了：

- 四条入口的全部十二种追问回应，以及每个结果的两级返回。
- 相关主题跳转、重新开始、页尾“再走一次”和刷新清空体验。
- 五个探索主题的十五条反馈、主题键盘切换、研究手记展开。
- 390、320、820 像素视口；未发现整页横向溢出，手机情境流程正常。
- JavaScript 语法检查；浏览器控制台未发现应用错误。

本次自动化浏览器只允许 HTTP/HTTPS，阻止了 `file://` 访问，因此没有在工具内完成双击文件模式的实测。项目使用普通脚本、相对路径和内存数据，已按直接打开的方式组织；已实际验证的运行方式是上面的 Node.js 本地预览。
